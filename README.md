# OYO FITNESS CENTER
Site vitrine premium interactif HTML/CSS/JS.

## Images
Toutes les images sont **100% locales** dans `assets/images/` (hero, services, team, gallery). Le site fonctionne hors-ligne et peut être publié tel quel. Sources originales : Unsplash (licence libre d'utilisation).

## Formulaire
Frontend uniquement : aucun envoi d'e-mail n'est prétendu sans backend/service.

## Publication
Remplacer `example.com` dans robots.txt et sitemap.xml par le domaine réel.
